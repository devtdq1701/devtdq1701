> **Sonatype Nexus Repository Manager 3 (NXRM3) Automation Tool**  
> *Cross-platform CLI built with Python 3, Typer, Rich, and httpx.*

- **Storage Analytics**: Multi-repository breakdown, Docker image space aggregation, and TTL disk caching.
- **Docker Lifecycle Pruning**: Independent per-image retention (`--keep-last <N>`), age filter (`--older-than 30d`), regex protection, and automated dry-run simulation.
- **Anti-Rate-Limiting**: Smart HTTP 429 backoff with `Retry-After` header parsing, jitter, and client pacing.
- **Task Automation**: Triggering system maintenance tasks (`Admin - Compact blob store`, `Docker cleanup`).
